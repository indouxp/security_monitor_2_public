## 2. rpi4-1（映像中継・メトリクスサーバー）

### 2.1 push_daemon.py — メトリクス受信デーモン

| 項目 | 内容 |
|---|---|
| リポジトリパス | `inventory/rpi4-1/push_daemon.py` |
| 配備先 | `/usr/local/sbin/push_daemon.py` |
| 起動方法 | systemd service（`push-daemon.service`）で常駐 |
| 待受 | `127.0.0.1:9091`（nginx が `/api/push` をプロキシ） |
| 概要 | クライアントから `POST /api/push` を受信し、送信元IPごとに最新値JSON（`{IP}.json`）と履歴NDJSON（`{IP}-history.ndjson`）を `/var/www/html/data/` に保存。履歴は最大2880行（24時間分）にトリミング。送信元IPは nginx の `X-Real-IP` ヘッダーを優先。 |

### 2.2 collect_metrics.sh — rpi4-1自己メトリクス収集

| 項目 | 内容 |
|---|---|
| リポジトリパス | `inventory/rpi4-1/collect_metrics.sh` |
| 配備先 | `/usr/local/sbin/collect_metrics.sh` |
| 起動方法 | systemd timer（`collect-metrics.timer`）で30秒間隔 |
| 概要 | rpi4-1自身のCPU使用率・CPU温度・ディスクI/O・メモリ使用率を収集し、`rpi4-1.json`（最新値）と `rpi4-1-history.ndjson`（履歴）に保存。push_daemon.py を経由せず直接ファイルへ書き込む。 |

### 2.3 app.js — WebUIフロントエンド

| 項目 | 内容 |
|---|---|
| リポジトリパス | `inventory/rpi4-1/@var@www@html@app.js` |
| 配備先 | `/var/www/html/app.js` |
| 起動方法 | ブラウザが nginx 経由で読み込み実行 |
| 概要 | 時計表示・WHEP接続（カメラ3台）・映像stall検出・全画面オーバーレイ・Chart.jsによるリソースグラフ（Panel4）を制御。詳細は[詳細設計書](詳細設計書.md)を参照。 |

## 3. Linuxクライアント（vostro 等）

### 3.1 push_metrics.sh — クライアントメトリクス収集・送信

| 項目 | 内容 |
|---|---|
| リポジトリパス | `inventory/client/lin/push_metrics.sh` |
| 配備先 | `/home/indo/bin/push_metrics.sh`（一般クライアント）／`/home/indou/bin/push_metrics.sh`（vostro） |
| 起動方法 | systemd timer（`push-metrics.timer`）で30秒間隔 |
| 概要 | CPU使用率・CPU温度・ディスクI/O・メモリ使用率を収集し、ローカル履歴へ保存後 `POST /api/push` で rpi4-1 へ送信。CPU温度は `thermal_zone`（RPi等）と `hwmon`（x86 PC等）の両方を参照。POST失敗時もローカル保存は完了しているため警告ログのみ。 |

### 3.2 start-camera-monitor.sh — Chromeキオスクモード起動

| 項目 | 内容 |
|---|---|
| リポジトリパス | `inventory/client/lin/vostro:@home@indou@start-camera-monitor.sh` |
| 配備先 | `/home/indou/start-camera-monitor.sh`（vostro） |
| 起動方法 | XDG autostart（`camera-monitor.desktop`）でログイン時に自動起動 |
| 概要 | スクリーンセーバー・画面オフを無効化（`xset`）し、Google Chrome をキオスクモードで起動して監視画面（`http://rpi4-1.tsystem.gr.jp/`）を表示。`--mute-audio` でWebRTC音声の大音量出力を防止。 |

## 4. Windowsクライアント

### 4.1 push_metrics.ps1 — クライアントメトリクス収集・送信

| 項目 | 内容 |
|---|---|
| リポジトリパス | `inventory/client/win/push_metrics.ps1` |
| 配備先 | Windowsクライアント任意ディレクトリ |
| 起動方法 | タスクスケジューラ（`\SecurityMonitor\push_metrics`）から `run_hidden.vbs` 経由で1分間隔 |
| 概要 | `Get-Counter` / WMI でCPU使用率・CPU温度・ディスクI/O・メモリ使用率を収集し、ローカル履歴へ保存後 `POST /api/push` で rpi4-1 へ送信。CPU温度は `MSAcpi_ThermalZoneTemperature`（BIOS非対応時は0.0）。 |

### 4.2 run_hidden.vbs — push_metrics.ps1の非表示起動

| 項目 | 内容 |
|---|---|
| リポジトリパス | `inventory/client/win/run_hidden.vbs` |
| 配備先 | push_metrics.ps1 と同一ディレクトリ |
| 起動方法 | タスクスケジューラのアクションから `wscript.exe` で起動 |
| 概要 | `WScript.Shell.Run(..., 0, True)` で push_metrics.ps1 をウィンドウスタイル0（完全非表示）で起動。`powershell.exe -WindowStyle Hidden` でも残るウィンドウ一瞬表示を防止するための中間スクリプト。 |

### 4.3 register_task.ps1 — タスクスケジューラ登録

| 項目 | 内容 |
|---|---|
| リポジトリパス | `inventory/client/win/register_task.ps1` |
| 配備先 | push_metrics.ps1 と同一ディレクトリ |
| 起動方法 | 管理者権限で手動実行（初回セットアップ時のみ） |
| 概要 | push_metrics.ps1 をタスク `\SecurityMonitor\push_metrics` として登録。登録直後実行用（Once）とログオン時実行用（AtLogon）のデュアルトリガーを設定し、ログオフ不要で即時開始。タスクスケジューラの最小繰り返し間隔は1分。 |

## 5. デプロイ用（開発機で実行）

### 5.1 release.sh — リモートへ配備

| 項目 | 内容 |
|---|---|
| リポジトリパス | `inventory/release.sh` |
| 使用方法 | `./release.sh [-c config_file] user@host` |
| 既定リスト | カレントディレクトリの `release.txt` |
| 概要 | リストに基づきローカル→リモートへ設定ファイルを配備。差分なしはスキップ、ローカルが新しい場合は自動配備、リモートが新しい場合はS/Y/C確認。ホームディレクトリ外はリモート `/tmp` 経由で `sudo mv`。 |

### 5.2 backup.sh — リモートから取得

| 項目 | 内容 |
|---|---|
| リポジトリパス | `inventory/backup.sh` |
| 使用方法 | `./backup.sh [-c config_file] user@host` |
| 既定リスト | カレントディレクトリの `backup.txt` |
| 概要 | リストに基づきリモート→ローカルへ設定ファイルを取得。release.sh と対をなすバックアップ用スクリプト。 |

## 6. 起動・実行間隔まとめ

| プログラム | 実行契機 | 間隔 |
|---|---|---|
| push_daemon.py | systemd service（常駐） | 常時 |
| collect_metrics.sh | systemd timer | 30秒 |
| push_metrics.sh | systemd timer | 30秒 |
| push_metrics.ps1 | タスクスケジューラ | 1分（最小値） |
| start-camera-monitor.sh | XDG autostart | ログイン時 |
| register_task.ps1 | 手動実行 | 初回セットアップのみ |
| release.sh / backup.sh | 手動実行 | 随時 |
| app.js | ブラウザ読み込み | 画面表示時 |
