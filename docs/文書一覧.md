## 4. 提出前チェックリスト

### 4.1 個人情報・機密情報確認

- [x] IPアドレスをプライベートアドレス範囲（192.168.x.x）に統一済みか
- [x] SSHパスワードが記載されていないか
- [x] Wi-Fi SSID・PSKが記載されていないか
- [x] カメラ設置場所の詳細住所・氏名が含まれていないか

### 4.2 文書品質確認

- [x] 基本設計書・詳細設計書のバージョン・作成日が最新か
- [x] 用語集の用語が基本設計書・詳細設計書と統一されているか
- [x] 環境設定手順書の手順が現行バージョンに対応しているか
- [x] 全体構成図が現行構成と一致しているか

### 4.3 テスト確認

- [x] テスト仕様書の全項目にテスト結果が記入済みか
- [x] 不合格（NG）項目に対して対処内容が記載されているか
- [x] 安定稼働テスト（24時間）が完了しているか
